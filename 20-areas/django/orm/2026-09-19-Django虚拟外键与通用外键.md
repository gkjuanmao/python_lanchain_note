# Django虚拟外键与通用外键
## Django 关联模型与查询优化完全指南

### 六、虚拟外键（不建约束的关联）

#### 1. 场景

跨数据库、跨服务的关联，无法用真正的 `ForeignKey`。


```python
class Order(models.Model):
    user_id = models.IntegerField(db_index=True)   # 只存 ID，不建外键
    product_id = models.IntegerField(db_index=True)
    quantity = models.IntegerField()
```

**用户信息在另一个服务/数据库里，不能建外键。**

#### 2. 手动关联


```python
order = Order.objects.get(pk=1)
user = UserService.get_user(order.user_id)   # 调远程服务
```

#### 3. 用 `GenericForeignKey`（Django 内置的通用外键）

适合"一个模型关联多种模型"的场景，比如评论可以挂在文章、视频、商品上。


```python
from django.contrib.contenttypes.fields import GenericForeignKey
from django.contrib.contenttypes.models import ContentType


class Comment(models.Model):
    content_type = models.ForeignKey(ContentType, on_delete=models.CASCADE)
    object_id = models.PositiveIntegerField()
    content_object = GenericForeignKey("content_type", "object_id")
    text = models.TextField()
```

**用法**：

```python
# 给文章加评论
article = Article.objects.get(pk=1)
Comment.objects.create(content_object=article, text="好文")

# 查评论所属对象
comment = Comment.objects.get(pk=1)
obj = comment.content_object   # 可能是 Article，也可能是 Video
```

**优点**：一个模型关联多种模型。  
**缺点**：查询性能差，不能用 `select_related`，要 `prefetch_related("content_object")`。

#### 4. 用 `GenericRelation` 反向查询

```python
class Article(models.Model):
    title = models.CharField(max_length=200)
    comments = GenericRelation("Comment")


article.comments.all()   # 查这篇文章的所有评论
```

#### 5. 虚拟外键的取舍

| 方案 | 适用场景 |
|---|---|
| 普通 `IntegerField` | 跨服务、跨库，完全手动 |
| `GenericForeignKey` | 一模型关联多模型 |
| 真正的 `ForeignKey` | 同库，有完整性要求 |
