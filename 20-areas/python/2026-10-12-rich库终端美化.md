# rich库终端美化


`rich` 是一个强大的 Python 库，它可以让你的终端输出变得**丰富多彩、格式精美**。你可以用它来添加颜色、样式、表格、进度条、Markdown 渲染、语法高亮等，非常适合用来开发命令行工具、日志系统或进行调试。

## 📦 安装

使用 pip 即可安装：

```bash
pip install rich
```

安装后，你可以运行 `python -m rich` 来查看 Rich 的所有功能演示。

## 🎨 核心功能与示例

### 1. 富文本与颜色

Rich 支持使用类似 BBCode 的标记语法来定义样式，如 `[bold red]` 表示粗体红色，`[underline green]` 表示下划线绿色，并且支持嵌套和十六进制颜色码。

```python
from rich import print

print("[bold red]警报![/] 服务器CPU使用率 [underline green]90%[/] :fire:")
print("[#FF5733 on #33FF57]赛博朋克风[/]")
```

### 2. 智能表格

使用 `Table` 类可以轻松创建格式整齐的表格，支持自动对齐、列样式和标题。

```python
from rich.console import Console
from rich.table import Table

console = Console()
table = Table(title="Python生态核心库")
table.add_column("库名", style="cyan")
table.add_column("用途", justify="right")
table.add_row("Rich", "终端美化")
table.add_row("Requests", "HTTP请求")
console.print(table)
```

### 3. 动态进度条

`Progress` 组件可以同时显示多个任务的进度、速度和剩余时间，非常适合长时间运行的任务。

```python
from rich.progress import Progress
import time

with Progress() as progress:
    task1 = progress.add_task("[red]下载中...", total=100)
    task2 = progress.add_task("[green]处理中...", total=50)
    while not progress.finished:
        progress.update(task1, advance=2)
        progress.update(task2, advance=1)
        time.sleep(0.1)
```

### 4. 语法高亮与代码打印

Rich 可以自动对 Python 代码进行语法高亮，让终端中的代码更易读。

```python
from rich.console import Console
from rich.syntax import Syntax

console = Console()
code = '''
def greet(name):
    print(f"Hello, {name}!")
'''
syntax = Syntax(code, "python", theme="monokai", line_numbers=True)
console.print(syntax)
```

### 5. 日志美化

通过 `RichHandler`，你可以让 Python 标准库 `logging` 的输出变得色彩分明、格式清晰，不同级别的日志一目了然。

```python
import logging
from rich.logging import RichHandler

logging.basicConfig(
    level="NOTSET",
    format="%(message)s",
    handlers=[RichHandler()]
)
logging.info("这是一条信息")
logging.warning("这是一条警告")
logging.error("这是一条错误")
```

### 6. 更友好的报错信息

`rich.traceback` 可以替换 Python 默认的异常回溯，提供带颜色、代码上下文和局部变量的增强报错信息，极大地方便调试。

```python
from rich import traceback
traceback.install(show_locals=True)

def divide(a, b):
    return a / b

divide(1, 0)  # 会显示增强的 Traceback
```

### 7. 对象查看与调试

`rich.inspect` 可以生成任何 Python 对象（类、实例、函数等）的详细报告，包括文档字符串、方法和属性，是调试的好帮手。

```python
from rich import inspect
inspect(list, methods=True)  # 查看 list 类的详细信息
```

## 💡 进阶提示

- **`Console` 对象**：对于更复杂的输出控制（如对齐、缩进、记录日志），建议使用 `Console` 类，它提供了比全局 `print` 更丰富的 API。
- **兼容性**：Rich 支持 Linux、macOS 和 Windows（新版 Windows Terminal 支持真彩色），并且要求 Python 3.8 或更高版本，在 Jupyter Notebook 中也能直接使用。

总的来说，`rich` 库能以极低的成本显著提升命令行程序的视觉体验和可读性，是 Python 开发者值得掌握的工具。
