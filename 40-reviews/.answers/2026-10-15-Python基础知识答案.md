# Python基础知识面试题 · 答案与解析

配套题目卷：[[2026-10-15-Python基础知识面试题]]

## 第 1 题 · 答案 A

- 解析：布尔值可以当整型对待，`True` 相当于 `1`、`False` 相当于 `0`。所以 `True + True` = `2`；`False + 1` = `1`；`True + False` = `1`。D 会报错，因为 Python 不支持字符串和数字的隐式相加，必须显式转换。
- 出处：[[2026-09-10-Python基础知识#数值类型]]、[[2026-09-10-Python基础知识#5. 隐式类型转换（自动发生）]]

## 第 2 题 · 答案 B

- 解析：`str()` 转为人类可读的字符串，`repr()` 转为解释器可读的字符串、用于调试，会给字符串再加一层引号；笔记的示例就是 `repr("hello")` → `"'hello'"`，所以打印结果是 `'hello'`。选 A 是把它当成了 `print("hello")`；选 C 是把它当成了 `json.dumps` 之类的双引号风格。
- 出处：[[2026-09-10-Python基础知识#2. 转换为字符串（str, repr, chr, ord, format）]]

## 第 3 题 · 答案 B

- 解析：集合里只能放可以被哈希的元素，字典可变、不可哈希，所以不能作为集合的元素。
  - A 错：集合官方定义是完全无序的，遍历顺序与插入顺序无关。
  - C 错：小整数看起来有序，是因为小整数的哈希值就是它本身，查询时按顺序打印出来了，不是集合排序。
  - D 错：集合会去重，笔记示例 `set([1,2,2])` → `{1,2}`。
- 出处：[[2026-09-10-Python基础知识#集合]]、[[2026-09-10-Python基础知识#3. 转换为容器类型（list, tuple, set, dict, frozenset）]]

## 第 4 题 · 答案

- `a` 打印 `[1, 2, [3, 4]]`，`b` 打印 `[1, 2, 3, 4]`。
- `append` 是整体添加：把 `[3, 4]` 这个列表当成一个元素加到末尾；`extend` 是分散添加：把另一个类型中的元素逐一添加进去。
- 出处：[[2026-09-10-Python基础知识#添加元素]]

## 第 5 题 · 答案

- 不准确。`__` 只是让属性无法通过对象名直接访问，并不是“绝对拿不到”。
- 笔记给出两种访问途径：第一种是 `_类名__属性名`；第二种是在类中定义方法（如 getter）来暴露。另外，在另一个 py 文件中通过 `from xxx import *` 导入时无法导入私有属性。
- 出处：[[2026-09-10-Python基础知识#封装]]
